Map Drawing Tool — approvals

Map update

Approved markers and drawings show in game within a minute or two, no restart and no mod update: on the full-screen map (M) and on the paper map in hand. Only the wooden map boards need a build: it writes a signed mod with the drawings baked into the map texture to MapDrawingTool\Build\@MapDrawingTool, which then has to go to the server and the Workshop as an update.
