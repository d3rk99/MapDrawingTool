[h1]Map Drawing Tool[/h1]

Let your players draw on your server's map. Territories, guild bases, trade spots, warnings, points of interest: players paint, stamp and label them in game or in a web map editor, you approve them, and they appear on everyone's map within a minute or two. No mod update, no restart, no Workshop re-download.

[hr][/hr]
[h2]What players see[/h2]
[list]
[*][b]The paper map in hand[/b] shows your server's map with every approved drawing on it.
[*][b]The full-screen map (M)[/b] shows the same drawings and markers, sharp at every zoom.
[*][b]Looking over a shoulder[/b] shows the map the other player is holding, their personal drawings included.
[*]Each server shows only its own community's drawings. One mod for everyone.
[/list]

[h2]Drawing in game[/h2]
Carry a pen, open the map (M) and press [b]D[/b]. A bar across the top shows every key.
[list]
[*][b]1[/b] line, [b]2[/b] marker, [b]3[/b] text, [b]4[/b] stamp. Left mouse draws or places, right mouse drags the map, the mouse wheel zooms.
[*]Lines in your pen's colour ([b]C[/b] switches pens), 5 fonts for text, the in-game marker icons.
[*]The vanilla pens are easy to tell apart: [b]Black, Red, Green and Blue Pen[/b], each with a coloured clip and its own description. (Pens rarely spawn: server owners may want to add them to their loot or spawn gear.)
[*][b]Stamps:[/b] 9 built in, or your own PNG images (up to 96 KB). Put them in [b]%LOCALAPPDATA%\DayZ\MapDrawingTool\stamps[/b] and pick them with [b][ ][/b].
[*][b]G[/b] everyone or only me, [b]L[/b] how long it stays, [b]Z[/b] undo, [b]Enter[/b] send.
[*][b]X[/b] lists your own drawings so you can remove them.
[/list]

[h2]Features[/h2]
[list]
[*]Web map editor: brush, eraser, stamps (built in or your own PNG), painted text, live map markers with the in-game icons.
[*][b]Personal or for everyone:[/b] players choose whether a drawing is shared with the server or only on their own map. You choose whether personal drawings need your approval.
[*][b]Lifespans:[/b] drawings can expire after a day, a week, a month... or stay. You set the limits.
[*]Players remove their own drawings, on the web page or in game.
[*]Owner approval page for every map at once: approve, reject, revoke, delete.
[*]Chernarus, Livonia, Sakhal and Nasdara, each on its own in-game paper map texture.
[*]Several servers on one web app: share one map between servers, or give each server its own.
[*]Player sign-in with Steam and/or Discord.
[*]Choose who may submit: anyone, anyone signed in, or only listed Steam accounts or Discord roles (for example Guild Leaders). Per map if you like. No Discord bot needed.
[*]Rate limits per player.
[*]Discord notifications when a submission is waiting for approval.
[*]Everything set up on a Settings page, no config file editing.
[*]Optional: unfolding the map shows only the paper in hand, M opens the full-screen map over it.
[/list]

[h2]Server setup[/h2]
You run two things: this mod on your DayZ server, and the Map Drawing Tool web app, a single program you run on a Windows PC or VPS (not on a rented game-server panel).

[b]Download the web app:[/b] [url=https://github.com/d3rk99/MapDrawingTool/releases/latest]github.com/d3rk99/MapDrawingTool/releases[/url] (MapDrawingTool-WebApp zip)
Full written guide: SERVER_SETUP.md inside the download.

[h3]1. Mod[/h3]
[list]
[*]Add [b]@MapDrawingTool[/b] to your server's -mod=, copy [b]keys\Derk.bikey[/b] to the server's keys folder, start the server once.
[*]Players need the mod too (required mod, like any other).
[/list]

[h3]2. Web app[/h3]
[list]
[*]Nothing to install: no Python, no DayZ Tools, no DayZ. The four official maps are included.
[*]Unzip the download somewhere permanent (e.g. C:\MapDrawingTool) and run [b]MapDrawingTool.exe[/b]. Leave its window open.
[*]Windows may say "Windows protected your PC" (the exe is not code-signed): click [i]More info[/i], then [i]Run anyway[/i].
[*]Open [b]http://127.0.0.1:8640/admin[/b] and paste the admin token from [b]Web\config.json[/b]. Everything else is on the [b]Settings[/b] tab.
[*]Make it reachable from the internet: forward port 8640, or better, put it behind HTTPS (Caddy does it in one line). Enter that address under Settings > Web address.
[/list]

[h3]3. Point your DayZ server at it[/h3]
Edit [b]profiles\MapDrawingTool\config.json[/b] and restart the server:
[code]{ "liveUrl": "https://map.yourdomain.com/", "lanUrl": "http://192.168.1.50:8640/", "mapId": "", "serverKey": "from Settings > Game servers", "pollSeconds": 60 }[/code]
Settings > Game servers on the web app shows these lines ready to copy.
[list]
[*][b]liveUrl[/b]: your public web app address. Players from the internet download the map from it, so not 127.0.0.1.
[*][b]lanUrl[/b] (optional): the web app's address on your own network. Players who joined your server over a private address (you, at home next to the server) and the server itself use it, so it works even when your router can't reach its own public IP. Leave it empty if the web app is elsewhere.
[*][b]mapId[/b]: empty = the server's own map. Several servers on the same terrain with different drawings: see SERVER_SETUP.md.
[*][b]serverKey[/b]: needed for drawing in game (and players' own stamps).
[*][b]paperTexture[/b] (added on first start, default true): false keeps the vanilla paper map in hand, with no texture download. Drawings still show on M.
[/list]

[h3]4. Give players the link[/h3]
Players open your web app address, or just draw in game. You approve on /admin.

[h3]5. Let pens spawn[/h3]
Drawing in game needs a pen, and vanilla DayZ never spawns them (nominal 0). The mod itself has [b]types\mdt_types.xml[/b], next to Addons and Keys (in @MapDrawingTool, or the Workshop folder 3833411645; also in the web app download and [url=https://github.com/d3rk99/MapDrawingTool/tree/main/Package/types]on GitHub[/url]): the four pens on shelves in towns, villages and offices, about 6 of each. Copy it to a folder [b]mapdrawingtool[/b] in your mission folder and add to [b]cfgeconomycore.xml[/b] inside <economycore>:
[code]<ce folder="mapdrawingtool">
    <file name="mdt_types.xml" type="types" />
</ce>[/code]
Or replace the four Pen_ entries in db	ypes.xml with the ones from the file. Or give players a pen at spawn.

[h3]Optional[/h3]
[list]
[*][b]Paper map in hand + M:[/b] mission cfggameplay.json "use3DMap": true, and enableCfgGameplayFile = 1; in serverDZ.cfg.
[*][b]Sign-in, who may submit, lifespans, personal drawings, Discord notifications:[/b] Settings tab on /admin.
[/list]

[h3]Updating[/h3]
Close the web app, unzip the new download over the same folder (your settings and submissions are kept) and start MapDrawingTool.exe again. Update the mod on the server too: server and players must run the same mod version.

[hr][/hr]
[h2]Good to know[/h2]
[list]
[*]Players download your map once per change (about 2.5 MB on Chernarus, 10 MB on the larger maps) in the background without FPS loss, the first time they hold a paper map. Old versions are deleted automatically.
[*]Players can turn the paper texture off for themselves: [b]%LOCALAPPDATA%\DayZ\MapDrawingTool\client.json[/b], "paper": 0. If a game ever closes during that download, it turns itself off for that player ("paper": 1 turns it back on). Download trouble? Ask for [b]progress.log[/b] in the same folder.
[*]The wooden map boards in towns keep the vanilla map.
[*]Built and tested on DayZ 1.30.
[/list]
