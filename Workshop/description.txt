[h1]Map Drawing Tool[/h1]

Let your players draw on your server's map. Territories, guild bases, trade spots, warnings, points of interest: players paint, stamp and label them in a web map editor, you approve them, and they appear in game within a minute or two. No mod update, no restart, no Workshop re-download.

[h2]What players see[/h2]
[list]
[*][b]The paper map in hand[/b] shows your server's map with every approved drawing on it.
[*][b]The full-screen map (M)[/b] shows the same drawings and markers, sharp at every zoom.
[*]Each server shows only its own community's drawings. One mod for everyone.
[/list]

[h2]Features[/h2]
[list]
[*]Web map editor: brush, eraser, stamps (built in or your own PNG), painted text, live map markers with the in-game icons.
[*]Owner approval page for every map at once: approve, reject, revoke, delete.
[*]Chernarus, Livonia, Sakhal and Nasdara, each on its own in-game paper map texture.
[*]Several servers on one web app: share one map between servers, or give each server its own.
[*]Player sign-in with Steam and/or Discord.
[*]Choose who may submit: anyone, anyone signed in, or only listed Steam accounts or Discord roles (for example Guild Leaders). Per map if you like. No Discord bot needed.
[*]Rate limits per player.
[*]Discord notifications when a submission is waiting for approval.
[*]Everything set up on a Settings page, no config file editing.
[*]Optional: unfolding the map shows only the paper in hand, M opens the full-screen map over it.
[/list]

[h2]Server setup[/h2]
You run two things: this mod on your DayZ server, and the Map Drawing Tool web app, a small program you host on a Windows PC or VPS (not on a rented game-server panel).

[b]Download the web app:[/b] [i]link to the GitHub release[/i]
Full written guide: SERVER_SETUP.md inside the download.
Video guide: [i]link[/i]

[b]1. Mod[/b]
[list]
[*]Add [b]@MapDrawingTool[/b] to your server's -mod=, copy [b]keys\Derk.bikey[/b] to the server's keys folder, start the server once.
[*]Players need the mod too (required mod, like any other).
[/list]

[b]2. Web app[/b]
[list]
[*]Needs Python 3.10+ (python.org), DayZ Tools (free on Steam) and DayZ or DayZ Server installed on the same PC.
[*]Unzip the download, run [b]setup.bat[/b], then [b]start.bat[/b].
[*]Open http://127.0.0.1:8640/admin and paste the admin token from Web\config.json. Everything else is on the [b]Settings[/b] tab.
[*]Make it reachable from the internet: forward port 8640, or better, put it behind HTTPS (Caddy does it in one line). Enter that address under Settings > Web address.
[/list]

[b]3. Point your DayZ server at it[/b]
Edit [b]profiles\MapDrawingTool\config.json[/b] and restart the server:
[code]{ "liveUrl": "https://map.yourdomain.com/", "mapId": "", "pollSeconds": 60 }[/code]
[list]
[*][b]liveUrl[/b]: your public web app address. Players' games download the map from it, so not 127.0.0.1.
[*][b]mapId[/b]: empty = the server's own map. Several servers on the same terrain with different drawings: see SERVER_SETUP.md.
[/list]

[b]4. Give players the link[/b]
Players open your web app address, draw, and submit. You approve on /admin.

[b]Optional[/b]
[list]
[*][b]Paper map in hand + M:[/b] mission cfggameplay.json "use3DMap": true, and enableCfgGameplayFile = 1; in serverDZ.cfg.
[*][b]Sign-in, who may submit, Discord notifications:[/b] Settings tab on /admin.
[/list]

[h2]Good to know[/h2]
[list]
[*]Players download your map once per change (2.4 MB on Chernarus, about 10 MB on the larger maps) in the background without FPS loss. Old versions are deleted automatically.
[*]The wooden map boards in towns keep the vanilla map.
[*]Built and tested on DayZ 1.30.
[/list]
